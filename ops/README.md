# Резервные копии 3X-UI

На сервере `kk-IdeaPad-5-15IIL05` установлен `3x-ui-backup.timer`. Он запускает
`backup-3x-ui.py` в 03:00 первого числа каждого месяца. При пропущенном запуске
`Persistent=true` запускает задачу после следующей загрузки сервера.

Скрипт делает согласованный снимок SQLite базы `/etc/x-ui/x-ui.db` через SQLite
Backup API, проверяет `PRAGMA quick_check`, добавляет `/root/cert` и сохраняет архив
в `/home/kk/Syncthing/VPN/3x-ui-backups/`. После успешной записи остаются только
три последних месячных архива. Папка доступна только пользователю `kk`, архивы
имеют права `0600`; в них находятся ключи VPN и сертификатов.

Проверка расписания и ручной запуск:

```bash
sudo systemctl list-timers 3x-ui-backup.timer
sudo systemctl start 3x-ui-backup.service
sudo journalctl -u 3x-ui-backup.service -n 30 --no-pager
```

Для восстановления остановите `x-ui`, распакуйте базу и сертификаты в исходные
пути, проверьте права и снова запустите `x-ui`. Делайте это на совместимой версии
3X-UI. Архив содержит `manifest.json` с SHA-256 базы.

Копии в этой папке синхронизируются на ПК, когда Syncthing запущен на обоих
устройствах. Первая копия от ноября 2026 года дополнительно перенесена на ПК
через SSH и сверена по SHA-256.
